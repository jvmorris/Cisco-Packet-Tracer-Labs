<h1>Cisco Packet Tracer Labs</h1>

<h2>Description</h2>

This repository contains hands-on Cisco Packet Tracer labs designed to demonstrate 
core networking concepts, device configuration, troubleshooting methodology, 
and enterprise network design principles.

Each lab simulates real-world networking scenarios including routing, switching, 
VLAN segmentation, and security implementation.

<br />

<h2>Utilities Used</h2>

- <b>Cisco Packet Tracer</b>

<br />

<h2>Environments Used</h2>

- <b>Windows 10</b> (22H2)

<br />

<h2>Lab List</h2>

<h3>Lab 01: Connect Multiple PC to Switch</h3>

<b>Objective:</b> Design and implement a simple Layer 2 Ethernet LAN in Cisco Packet Tracer by connecting two PCs to a switch, assigning appropriate IP addresses, and verifying end-to-end connectivity using ping. 
<br />

<h3>Lab 02: Building a Small LAN with a Router and Switch </h3>

<b>Objective: </b>Design and implement a routed LAN in Cisco Packet Tracer by connecting three PCs to an access‑layer switch, uplinking the switch to a router, assigning IP addresses and default gateways, and verifying connectivity between hosts and the router with ping. 
<br />

<h3>Lab 03: Basic VLANs and Trunking </h3>

<b>Objective: </b>Configure static VLANs and an 802.1Q trunk in Cisco Packet Tracer by segmenting two switches into multiple VLANs, assigning access ports for eight PCs in a single subnet, and verifying end‑to‑end connectivity across the trunk.
<br />

<h3>Lab 04: Multiple VLANs with Router Sub‑Interfaces (Router‑on‑a‑Stick) </h3>

<b>Objective: </b>Configure multiple VLANs and router sub‑interfaces in Cisco Packet Tracer by assigning unique IP subnets per VLAN, enabling 802.1Q encapsulation on a router‑on‑a‑stick link, and verifying inter‑VLAN connectivity between hosts.
<br />

<h3>Lab 05: Static Routing Between Multi‑VLAN Networks</h3>

<b>Objective: </b>Configure static routes between two multi‑VLAN networks in Cisco Packet Tracer by connecting routers over a serial link, assigning IPs to router interfaces and VLANs, enabling trunk ports, and using gateways of last resort to provide end‑to‑end connectivity between workstations.
